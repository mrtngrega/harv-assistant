  type: feedback

When the user starts a new project, create its folder at once in their projects folder (Harv's Settings › Projects, chosen at setup), with git, a starter `CLAUDE.md` and a GitHub repo. The one question first: private or public. Use the name they give, or a short lowercase-hyphen name from the description, and say which folder was made. In Harv this is the `start_project` tool (persona rule 8).
