# Starter files

The `harv-setup` skill copies these on the first setup. After that they belong to the user: edit them freely, and Harv and Claude Code keep them up to date as you work.

- `harv-memory/` → `~/.harv/memory/`: Harv's first notes. `user-profile.md` is filled from the setup's questions; the rest are general rules (how to answer, how to work, the plan limits, the Google connectors).
- `claude-memory/` → `~/.claude/projects/<this repo's slug>/memory/`: Claude Code's memory for developing Harv: the routines (start, bye, fresh) and the working rules that made Harv. `MEMORY.md` is the index Claude Code loads every session.

No personal data here: these are rules, not facts about anyone.
