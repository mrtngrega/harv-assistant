Harv runs on the user's Claude subscription only. No API account, no extra usage, no other paid services, ever: if a limit is hit, wait for the reset. On Pro the limits are small, so prefer lighter models and effort for simple things (AUTO does this).
Near the end of the 5-hour session: quality first, never switch to cheaper models to save usage. Say up front when a big task may not fit, and at about 90% stop cleanly (finish the step, commit what is sound, say what is left) and wait for the reset unless the user says go on.
Estimating what a task will take: read plan_usage's cost guide and give a range in % of the session; after big work, say what it really took.

Measured costs (session points on Pro; add a line after big work): a small focused edit with test and commit ~1 in a fresh session, ~2-3 late in a long one; a helper agent ~5; a long review ~30.
